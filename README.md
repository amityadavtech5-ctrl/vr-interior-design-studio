# VR Interior Design Studio — Static Website

Static HTML/CSS/JS website for VR Interior Design Studio.

## Pages
- `index.html` — residential home interior design landing page
- `work.html` — residential project portfolio
- `contact.html` — Google Form enquiry page

## Deployment
Upload the contents of this folder to any static web host. No Flask, PHP, Python runtime or server-side processing is required.

## Contact form
The Contact page links to the configured Google Form. Replace the Google Forms URL in `contact.html` if the form URL changes.

## SEO
The site includes page titles, meta descriptions, canonical URLs, semantic headings, descriptive image alt text, internal links, robots.txt, sitemap.xml and structured data on the home page.
